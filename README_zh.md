# Go 实时聊天客户端与服务器

一个功能丰富的实时聊天应用，使用 Go 语言实现，支持群聊和私聊，并提供直观的终端用户界面。

## 功能特点

- 实时群聊和私聊消息
- 基于主题的频道讨论系统
- 用户认证与注册
- 消息历史记录和在线用户列表
- 屏蔽和禁言功能
- 支持鼠标操作的终端界面
- 新消息声音提示
- 可自定义的服务器配置

## 安装

1. 确保系统已安装 Go（推荐使用 1.16 或更高版本）。
2. 克隆仓库：
   ```
   git clone https://github.com/yourusername/go-chat.git
   cd go-chat
   ```
3. 安装依赖：

```
go mod tidy
```

## 使用

1. 启动服务器：
   ```
   go run server/main.go
   ```
2. 在另一个终端中启动客户端：
   ```
   go run client/main.go
   ```
3. 按照屏幕提示登录或注册。

## 架构

应用采用客户端-服务器架构：

- **服务器**：管理连接、路由消息并处理用户认证。
- **客户端**：提供终端界面供用户交互和通信。

## 组件

### 服务器

- `main.go`：服务器应用的入口文件。
- `server.go`：核心服务器逻辑和连接管理。
- `message_router.go`：在客户端之间路由消息。
- `auth.go`：处理用户认证和注册。
- `channels.go`：管理聊天频道及其操作。
- `chat_history.go`：存储和检索消息历史。

### 客户端

- `main.go`：客户端应用的入口文件。
- `client.go`：核心客户端逻辑和服务器通信。
- `message_handler.go`：处理收发消息。
- `ui_manager/`：包含终端界面的实现。

### 共享

- `protocol/`：定义客户端与服务器之间的通信协议。

## 配置

服务器可通过环境变量配置：

- `CHAT_PORT`：服务器端口号（默认：7007）

## 命令

用户可通过以下命令与聊天应用交互：

- `/whisper <用户名> <消息>`：发送私聊消息
- `/reply <消息>`：回复最后收到的私聊消息
- `/mute <用户名>`：禁言某用户
- `/unmute <用户名>`：解除禁言
- `/block <用户名>`：屏蔽用户
- `/unblock <用户名>`：解除屏蔽
- `/ch create <名称> <密码> <最大用户数> <公开|私有>`：创建新频道
- `/ch join <名称> <密码>`：加入现有频道
- `/ch leave`：离开当前频道
- `/ch users`：列出当前频道用户
- `/ch list`：显示活跃频道
- `/ch kick <用户名>`：踢出用户（仅频道所有者）
- `/ch ban <用户名>`：封禁用户（仅频道所有者）
- `/clear`：清空聊天屏幕
- `/quit`：退出应用
